逆転の実話 アップロード

このアプリは、YouTube チャンネル「逆転の実話」の運営者が、自分のチャンネルに動画をアップロードし、題名・説明・サムネイルなどを設定するためだけに使う道具です。運営者以外の人が使うことはありません。

プライバシーポリシー

このアプリは、YouTube Data API を通じて、運営者自身の YouTube アカウントにだけアクセスします。

  • 使う情報：運営者のチャンネル名と、運営者がアップロードする動画・題名・説明・サムネイル。
  • 使い方：運営者のチャンネルへの動画のアップロードと、その設定のためだけに使います。
  • 保存：アクセスのための認証情報は、運営者のパソコンの中にだけ保存します。ほかの場所には送りません。
  • 第三者への提供：どの情報も、第三者に渡したり、売ったりしません。
  • 取り消し：Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

このアプリによる Google API から受け取った情報の使用と他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

YouTube の利用には YouTube 利用規約が、Google のプライバシーについては Google プライバシーポリシーが適用されます。
